# GOLÍN — demo para probar

Roguelite de futbolín: jala, suelta, rebota y multiplica.

**Jugar:** https://eduresvez8-code.github.io/golin-demo/

- Jala hacia atrás desde el balón y suelta. El primer picadito trae un tutorial corto.
- Funciona mejor en computador (Chrome, Edge o Safari recientes), con ratón o trackpad.

## Ayúdanos a balancearlo
El juego guarda un registro de tus partidas **solo en tu navegador**. Cuando termines de jugar:
1. Pulsa la tecla **D** (abre el panel de pruebas).
2. En *Registro de partidas*, pulsa **Descargar registro (.json)**.
3. Mándanos ese archivo. ¡Gracias!
